7. What is calibration in modelling?
   This means changing inputs and seeing hoe it affects model outputs. If it changes small and causes a small or no change then the model is robust, but a small input change and a large output change might be unreliability.

8. What  is a deterministic model
	A deterministic model is  a model that has no randomness. It means no matter how many times you run it, the same inout will always give the same outbut.

9. What is a stochastic model?
	A stochastic model is  a model that has randomness. It means if you run the input many times, then you are likely to get varying outputs. This means you run it several times to get the mean or average. examples are coin flips.

11. Nigeria generates 5,801 MW and needs 33,000 MW. If 11.87 MW is added per year, how many years to reach the target?
```
- Currently Generated MW (CGM) = 5,801 MW
- Projected MW needed (PMW) = 33,000 MW
- Average MW added per year (AMW) = 11.87 MW
```

$$\text{Number of years} = \frac{\text{PMW} - \text{CGM}}{\text{AMW}}$$
$$= \frac{3300 - 5801}{11.87}$$
$$= \text{2291}$$
