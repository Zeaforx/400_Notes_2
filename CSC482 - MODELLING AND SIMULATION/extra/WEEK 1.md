# Introduction to System Modelling for Python

In order to define the behaviour of a system under various environments, accomplishing a model of a system with a system study is practically a wise decision. Modelling helps you study a system in order to analyse its behaviour. You can do experiments with the system. Sometimes this is not possible, especially if it is at its conceptual stages. That is the main reason to associate with a system.

## Definition of a Model

- A model is a collection of relevant information that plays a vital role for the purpose of studying a system to provide all possible representation of a system.
    
- A model of a system helps the system analyst to understand the functionality of a system and communicate it to customers and clients.
    
- A model is just a simplified version of a system at some particular point in time and space intended to promote understanding of the real system.
    
- A model is a version of a real system.
    
- A model of a system is anything a system can be applied to in order to answer questions about the system.
    
- A model is a pattern, representation, or a description designed to show the structure or working of an object, system, or concept.
    

## Definition of Modelling

The process of organizing knowledge about a given system. It is a way of creating or developing a model.

## Processes of Modelling

1. **Problem formulation**
    
2. **Data collection and analysis** How to collect data:
    
    - Questionnaires
        
    - Interviews
        
    - Observations
        
    - Experiments
        
3. **Simulation model development**
    
4. **Model verification, validation, and calibration**
    
    - **Verification:** Are we building the system right?
        
    - **Validation:** Are we building the product right?
        
    - **Calibration:** Using x and y to represent entities (e.g., students).
        
5. **Input data analysis**
    
6. **Sensitivity estimation**
    

## Types of Models

1. Deterministic and stochastic models
    
2. Static and dynamic models
    

### Example Calculation

Given that NG generates 5801 MW, calculate how many years it will eventually take us to get 24 hrs light.

**Formula variables:**

- Average MW generated per year (AMW) = 11.87 MW
    
- Projected MW (PMW) = 33,000 MW
    
- Currently generated MW (CGM) = 5801 MW
    

**Equation:**

Number of years = (PMW - CGM) / AMW

### Deterministic vs. Stochastic Models

**Deterministic model:** Produces exact results for the same environment. There is no probabilistic or random component. The output is determined once by the set of input quantities and relationships. It takes a lot of computer time to evaluate what the output can be.

**Stochastic model:** Involves the process of modelling a system output with at least some random input components. A probability problem is stochastic. The output only estimates the true characteristics of the system model.

The random effects of stochastic models mean:

1. They have one or more random inputs.
    
2. You need to repeat experiments a number of times.
    
    The need to have confidence in the results output from stochastic systems sometimes leads to doubt.
    

### Static vs. Dynamic Models

**Static model:** This is where set state is independent of time. A static simulation model is a representation of a system at a particular time. You use these models to represent a system in which time simply plays no role.

**Dynamic model:** The system state changes with time. A dynamic simulation model represents a system as it evolves over time.

### Mathematical Model Classification Summary

- **Deterministic:** Input and output variables are fixed values.
    
- **Stochastic:** At least one of the input and output variables is probabilistic.
    
- **Static:** Time is not taken into account.
    
- **Dynamic:** Time of variables is taken into account.
    

A model should not be so complex that it is impossible to understand. An important issue in modelling is model validity. Generally, a model intended for a simulated study is a mathematical model development with the help of simulation software.

# Simulation

A simulation of a system is the operation of a model of the system. You can reconfigure the operation and experiment with regenerate input data. Simulation is a tool used to evaluate the performance of an existing, entire, or purposed system under different configurations over a long period of time.

Simulation comes after modelling. A modelled system helps simulation to work.
